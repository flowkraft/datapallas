# Who may open each door of this server: the decision, in one place.
#
# Every line is METHOD path -> ROLE, derived from the @PreAuthorize annotations by
# EndpointRoleMatrixTest and compared against this file. Changing an annotation, adding an
# endpoint or removing one makes that test fail until somebody decides what this file should say.
# That is the point: a role is a decision, not whatever the code happened to end up with.
#
# IF THE TEST FAILS: do not paste the derived matrix over this file to make it green. Read the lines
# it names, one at a time, and decide each one - a row here is somebody's access to their own work,
# and a row that changes without being read is how a door opens quietly. (Same rule, and for the same
# reason, as the golden lines in NorthwindFrozenTest.)
#
# ROLE is the weakest role admitted; every stronger role is admitted too (see Role.includes).
# "(none)" means no annotation, which is itself a decision - the door is opened by SecurityConfig
# or narrowed by a data check inside the handler. Each of those carries, on the comment line
# directly above it, the reason it is open; the test refuses a "(none)" line without one.

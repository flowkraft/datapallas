Cube Stories

One card per cube — tick a field, see the answer, see the SQL

Every cube DataPallas ships, live. Each card below is one cube of the semantic layer, with the questions it was written to answer. Click Show Me on a question and the fields it needs are ticked for you; tick your own and the answer follows. Each card also offers View SQL, the statement your selection would be answered by — for any of the databases DataPallas writes SQL for, not only the one the rows come from — and View Code, the cube’s own definition.

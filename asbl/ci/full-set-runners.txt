# asbl/ci/full-set-runners.txt: STEP 1'S FULL SET IN 2, 3 OR 4 RUNNERS, each spec file whole in one runner.
#
# What it is: a release's step 1 may run its full set (the web lane, dp-ci.sh's full mode) split into N jobs, each in a
# runner of its own (a Docker engine of its own, asbl/ci/e2e-runners.sh), N being the job's
# SPLIT_E2E_FULL_SET_EXECUTION_INTO_N_PARALLEL_JOBS. With 1 (the default) runner 1 runs the whole full set: no list.
# These are the layouts for 2, 3 and 4, split by area, so that each runner takes about the same time.
# How it is read (asbl/ci/full-set-runners.py):
#   1. Every line that is not blank or a comment is "<jobs> <runner> <spec file under frend/reporting/e2e/>", or
#      "<jobs> <runner> the-rest".
#   2. In each layout exactly one runner is "the rest": it runs its own files and every file of the full set that no
#      other runner of the layout lists, so a new spec file always runs (in the rest) until someone places it.
#   3. The full set is what dp-ci.sh's full mode selects at the checkout (its E2E_SPEC): every *.spec.ts but the auth
#      file (auth-authorization-server, which runs on its own before) and the Electron-only file
#      (let-me-update-migrate-configuration).
# The check (full-set-runners.py check; refused, exit 2, naming the file): a file in two runners of a layout; a file
# the full set leaves out (the auth file, the Electron-only file); the specs that use the test licence key (found by
# reading the specs: they activate, check or deactivate it, and the licence server holds one seat for it) not all in
# one runner. A listed file that no longer exists is a WARN only.
# Times (test minutes on 16.6.2's web full set; 16.6.1's docker-server full set in brackets; full-set-runners.py times):
#   4 jobs: 165 (160), 152 (155), 159 (148), 134 (132)   mean 152 (149)   the farthest 11.9% off
#   3 jobs: 195 (190), 194 (196), 220 (209)              mean 203 (198)   8.2% off
#   2 jobs: 299 (292), 310 (304)                         mean 304 (298)   2.0% off
# Callers: release-step1.sh and the orchestrator (step 1 in N jobs) through full-set-runners.py pattern, which gives
# each runner its E2E_RUNNER_FILES; a person or an agent, after moving a file:
#   python3 asbl/ci/full-set-runners.py check
#   python3 asbl/ci/full-set-runners.py files 4 2
#   python3 asbl/ci/full-set-runners.py times 4 --report <a full set's -playwright.json>
# Test: asbl/ci/tests/test-runner-lists.sh.
